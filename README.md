# VEX Shop

De officiële website van **VEX Shop** — gericht op premium FiveM server builds en websites voor communities en projecten.

De website is gebouwd als statische site en is direct geschikt voor **GitHub Pages**.

## Features

* Moderne donkerblauwe / electric-blue VEX stijl
* Volledig responsive voor desktop, tablet en mobiel
* Geanimeerde interface en hover-effecten
* FiveM server-aanbod
* Website-diensten
* Review-sectie
* Discord-integratie voor support en aanvragen
* Preview-sectie op de homepage
* Geschikt voor GitHub Pages
* Ondersteuning voor een eigen domein via `CNAME`
